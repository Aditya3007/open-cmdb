# Local Development

This document describes the prerequisites required to develop and run Open CMDB locally.

## Prerequisites

Install the following tools:

| Tool | Recommended Version | Purpose |
|---|---|---|
| Git | 2.40+ | Source control |
| Docker Desktop | Latest stable | Containers and local infrastructure |
| Python | 3.11+ | 3.11.9 | Backend and data pipelines |
| Node.js | 22+ LTS | 26.0.0 | Frontend development |
| npm | 10+ | 11.12.1 | Frontend package management |
